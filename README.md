# Website Quick Start

This folder is the publishable website output for Zhang Mantang's official calligraphy site.

## What This Folder Is

- `index.html` and route folders such as `works/`, `exhibitions/`, `news/`, `about/`, `en/` are static page shells.
- `js/` contains the browser runtime that loads data, renders pages, handles filters, search, language switching, galleries, and routing.
- `css/style.css` contains the visual system and responsive layout.
- `data/` is the runtime content used by the browser: `profile.json`, `works.json`, `exhibitions.json`, and `news.json`.
- `images/` contains the image assets copied into the publish output.
- `assets/fonts/` contains local web fonts.

## Important Source Of Truth

For durable edits, change the repository-level source files first, then rebuild `site/`.

- Content source: `../data/*.json`
- Image source: `../images/`
- Static shell generator: `../scripts/generate_static_route_shells.py`
- Publish build script: `../scripts/build_site_publish.py`
- Runtime JavaScript source: `js/*.js`
- Runtime CSS source: `css/style.css`

Do not edit generated route files by hand unless the change is intentionally temporary. Files such as `works/work-041/index.html` are regenerated by the build script.

## Local Preview

From the repository root:

```powershell
py -m http.server 8000
```

Open:

```text
http://127.0.0.1:8000/site/
```

The site is often previewed under `/site/`, so resource paths must work from that subdirectory. The page shells use relative paths, and `js/state.js` derives the runtime asset base from the actual loaded script path.

## Rebuild

From the repository root:

```powershell
py scripts/build_site_publish.py --repo-root .
```

This regenerates route pages and copies runtime `data/`, `images/`, and `favicon.ico` into `site/`.

## Common Tasks

- Remove or add works, exhibitions, or news: edit `../data/works.json`, `../data/exhibitions.json`, or `../data/news.json`, then rebuild.
- Change artist profile, homepage copy, contact fields, or homepage hero image: edit `../data/profile.json`, then rebuild if static metadata should update.
- Change layout or interactions: edit `css/style.css` or `js/*.js`.
- Fix detail page images: update `cover_image` and `gallery_images` in the relevant JSON item. `cover_image` appears first in galleries.
- Avoid duplicate gallery images: compare visual content, not only filenames, because the same source can exist at different resolutions.
